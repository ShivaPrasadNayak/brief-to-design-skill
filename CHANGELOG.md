# Changelog

## 1.0.0 (2026-10-09)
First public release.
- Nine-step creative-director workflow (understand, meaning, concept, Direction Lab, design system, story, build, render-and-fix, deliver).
- Output to PPTX, HTML slide decks, DOCX, Markdown notes and landing pages.
- `render.py`: any format to page images, contact sheet and HTML overflow QA (PowerPoint/Word on macOS, LibreOffice elsewhere, Chrome/Edge for HTML).
- `contrast.py`: WCAG contrast check with suggested fixes. `fetch_image.py`: openly licensed photo search with automatic credits.
- Three worked examples with real output files.
