# Contributing

Thanks for helping make AI output look designed.

**Most wanted**
- New worked examples: a brief, the three directions, the pick, and the rendered output (add to `skills/brief-to-design/examples/`).
- Renderer support: PowerPoint/Word automation on Windows, more Linux browsers.
- References: palette starting points, layout compositions, font pairings that ship with common software.

**Rules**
- Keep `SKILL.md` under ~150 lines; detail belongs in `references/`.
- Every new script must run without API keys or paid services.
- Render your change (`scripts/render.py`) and attach a screenshot to the pull request.
- Images you add must be openly licensed, with credit in `CREDITS.json`.

**Show and tell**: share what you built in Discussions; good examples get featured in the README.
